    After downloading

    A downloaded file can never arrive executable — browsers always write it read-only, which is why double-clicking gives a “permission denied” alert. Run it through zsh instead; that needs no chmod and no security settings.

    zsh "$HOME/Downloads/prioritise-fonts.sh"

    The script detects which Office apps are actually running, asks before quitting anything, writes the preference, verifies it landed, then runs the open → quit → reopen cycle Office needs before the fonts show up. The command above does not do that last part.
